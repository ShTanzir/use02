This login is a UI access gate only — GitHub Pages cannot enforce server-side security. It hides the editor from casual visitors, but the password hash still lives in this static site's code. For real access control, put this site behind GitHub OAuth, a GitHub App, or a small backend, and never commit real secrets here. Default credentials: admin / modda-admin — change the password hash before publishing.

Uploads browser

Lists files already committed to the uploads/ folder on GitHub. GitHub Pages can't accept new file uploads from a browser — push files via GitHub first, then pick them here.

Uses the public, unauthenticated GitHub Contents API, so it only works for public repositories and is subject to GitHub's low rate limit for anonymous requests.
